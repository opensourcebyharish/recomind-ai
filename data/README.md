# Data Directory

- `raw/` - Original datasets (e.g., MovieLens CSV files). Not committed to git.
- `processed/` - Cleaned/transformed data used by the ML pipeline. Not committed to git.
- `models/` - Trained model artifacts (pickles/npz). Not committed to git.

Place your CSV files in `data/raw/` when using a real dataset. A small sample dataset will be added in Phase 5.
