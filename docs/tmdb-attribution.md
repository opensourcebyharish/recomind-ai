# TMDB Integration - Attribution Requirements

This application uses the [TMDB API](https://www.themoviedb.org/) but is not endorsed or certified by TMDB.

## Required Attribution
According to TMDB's terms of use, we must include attribution. Add the following notice in the UI:

- **Logo**: Display the TMDB logo when using TMDB data
- **Text**: "This product uses the TMDB API but is not endorsed or certified by TMDB."

## Implementation
The attribution is displayed in the TMDB catalog section when TMDB data is being shown.
